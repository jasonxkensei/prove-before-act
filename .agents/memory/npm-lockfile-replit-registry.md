# npm lockfile — Replit registry proxy

## The rule
Never commit a `package-lock.json` generated by a plain `npm install` on Replit.
Replit routes npm through an internal proxy (`http://package-firewall.replit.local/npm/`).
All `resolved` URLs in the lockfile will point to that address, which is unreachable
from GitHub Actions and any external CI — causing a 72-second hang then
`npm error Exit handler never called!`.

**Why:** Replit overrides `npm config registry` to its local firewall proxy.
The lockfile bakes those URLs at generation time.

**How to apply:** Always regenerate with:
```
npm install --registry https://registry.npmjs.org
```
Verify the lockfile contains zero Replit-local URLs before committing:
```
python3 -c "import json; pkgs=json.load(open('package-lock.json'))['packages']; print(sum(1 for p in pkgs.values() if 'replit.local' in p.get('resolved','')))"
```
Expected output: `0`
